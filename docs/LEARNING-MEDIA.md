# Learning guides and media provenance

Added 23 November 2026. Four short Arabic/English guides cover verification codes, payments, impersonation and suspicious links. Each uses three illustrated steps with Back/Next. Two topics also have 24-second silent videos in each language (four MP4 files total).

The scripts, simple geometric illustrations and videos were created for T2AKKAD with AI coding assistance; no third-party video, soundtrack, police branding, voice clone or TTS is used. The clips are original storyboard illustrations, not recordings of a real device or an official police training resource. The local Chrome renderer draws system Arial text; font files are not distributed. The asset-specific permission is in `assets/learning/LICENSE.txt`; preserve it when redistributing the files. Team contribution/provenance review remains part of the submission checklist.

Source text: `src/lib/learning.json`. Reproducible generator: `scripts/build-learning-videos.mjs`. Generated files: `assets/learning/{codes,payments}-{en,ar}.mp4`. The generator uses the existing Playwright development dependency, installed Chrome and ffmpeg on PATH; it renders temporary frames under ignored `.local/learning-frames`. Run `node scripts/build-learning-videos.mjs` after editing a video script. Generating videos is optional for running the app because the outputs are committed. ffmpeg is a build tool, not bundled in the app.

Playback uses SDK-compatible expo-video (MIT; preserve its dependency license). Media is bundled locally, does not autoplay or loop, and exposes play/pause plus native seek controls. It pauses when leaving Learn; background playback and picture-in-picture are disabled. Each video has the same complete written steps underneath and graceful error text. No audio track exists. Physical-device playback still requires an iPhone/Android check; web playback and successful exports alone are not that check.

Topics are optional: All topics, Messages & calls, Money & shopping, Accounts & passwords. The choice is saved only in local preferences and shared by Alerts/Learn; it is never sent to the backend or used to profile the user. All topics is the default and remains available. Alert matching is a simple bilingual keyword filter over the existing approved title/excerpt, not AI classification or a risk judgement. It can miss relevant articles, so users can reset it. The collector, approved sources, date/staleness rules and source links are unchanged.
